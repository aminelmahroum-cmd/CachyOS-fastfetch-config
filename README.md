# My custom fastfetch configuration for cachy OS

## installation:

1. make sure fastfetch is installed:
  ```bash
sudo pacman -S fastfetch
  ```
2. clone this repo using git to your pc:
  ```bash
git clone https://github.com/aminelmahroum-cmd/CachyOS-fastfetch-config.git
  ```
3. make a fastfetch directory (skip this if you already have one):
  ```bash  
mkdir -p ~/.config/fastfetch
  ```
4. Copy the config and logo to the fastfetch configuration folder:
  ```bash
cp CachyOS-fastfetch-config/* ~/.config/fastfetch/
  ```
